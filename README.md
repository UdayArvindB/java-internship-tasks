# Java Internship Tasks — Project Bundle

This bundle contains three separate Java 17 Maven console applications:
1. Student Grade Tracker
2. Stock Trading Platform (simulation)
3. Rule-based AI FAQ Chatbot

## Requirements
- JDK 17 or newer
- Apache Maven 3.8+

Each project has its own README and can be opened separately in IntelliJ IDEA, Eclipse, or VS Code with Java extensions. These are independent projects; run Maven commands inside each project folder.

## Suggested submission checklist
- Run each project locally and test valid and invalid inputs.
- Add screenshots of actual program runs to each README if your internship asks for evidence.
- Update author/contact details only with your own information.
- Be prepared to explain the code and design decisions. The chatbot is explicitly rule-based, and stock prices are sample values—not live market data.
